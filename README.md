# Show Me the Monet

An endlessly varied, procedurally painted *Bridge over a Pond of Water Lilies* (after Claude Monet, 1899), with a rowboat mode that lets you drift into the painting.

- **Easel**: every seed paints its own variation of the Japanese footbridge over the lily pond. Seed `1899` paints Monet's composition.
- **Drift**: step into the painting and row through an endless water garden built from painted cutout layers, like a diorama.

```sh
npm install
npm run dev
```

Plain TypeScript, Vite and canvas 2D. No runtime dependencies. `npm run build` produces a single self-contained `dist/index.html`.
